# teknofest_interface

A C#-based user interface developed for our Hyperloop vehicle in the 2023 Teknofest competition, enabling control of all vehicle functions and real-time monitoring of its status. This interface is designed to manage the entire operational process, from starting the vehicle to stopping it; C#’s speed was leveraged to prevent delays in real-time data tracking. A relatively simple design was chosen. 

We used also other system and hardware equipment such as ardunio, raspberry pi, python etc. All system could be under control with this interface.
